# 认知工作区 0.0.2

首个 GitHub 公开发行版本：可安装在本地的 Windows 目标式学习软件。

## 功能

- 目标确认、阶段导航和范围约束。
- 阅读优先界面：完整推理步骤、连续例子、适用边界和回归整体。
- 术语预览、按需递归展开、父问题提示与返回阅读位置。
- 三维/平面认识网络、节点拖动与局部地图放大。
- 自述理解与课后题证据分开保存，目标完成由用户确认。
- 本地笔记、修订历史与恢复、Markdown 导出。
- DeepSeek 自带密钥接入，Pi SDK 独立进程，可停止模型任务。

## 下载与使用

下载 `Cognition-Workspace-Setup-0.0.2.exe`，按向导安装。安装包包含 Electron 与 Python 后端，不需要另装开发环境。

平台为 Windows x64，安装包尚未进行发布者代码签名。可先体验无需模型的注意力示例；自定目标与问答需要配置自己的 DeepSeek API Key。源码与安装包不包含作者的密钥或学习记录。

已有本地试用版的用户请先关闭旧程序。旧示例可点击“升级这个示例的讲解”，保留笔记、答题证据与布局。默认数据目录仍为 `%APPDATA%/cognition-workspace`。本次公开版本使用 `0.0.2`；此前文档的 v0.2 和本地试用包 0.2.0 属于历史迭代标记。

## 当前边界

模型内容尚未经外部信源核验，结构校验不等于知识正确性验证。免费信源自动研究、语音、工具执行沙箱、Notion 同步和自动更新尚未实现。

`SHA256SUMS.txt` 提供安装包校验值。源码可通过 Release 自动提供的源码归档或仓库获取。
